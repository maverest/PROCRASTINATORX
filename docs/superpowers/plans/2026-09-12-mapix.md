> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter Mapix à PROCRASTINATORX avec quatre modes de quiz, sept zones géographiques, une carte SVG locale et des résultats de partie sans persistance.

**Architecture:** Un catalogue JSON versionné contient les 195 pays, leurs noms français, drapeaux, continents et alias. Un moteur Python et un état verrouillé valident les parties côté serveur ; une interface HTML/CSS/JavaScript rend une carte SVG Natural Earth embarquée et envoie des actions typées au blueprint Flask de Mapix.

**Tech Stack:** Python 3.12, Flask 3, pytest 8, HTML/CSS/JavaScript sans framework, SVG Natural Earth 1:10m, PyInstaller.

**Spec:** `docs/superpowers/specs/2026-09-12-mapix-design.md`

## Global Constraints

- La liste jouable contient exactement 195 États : 193 membres de l'ONU, plus le Vatican et la Palestine.
- Les territoires dépendants et les zones disputées ne sont pas des réponses supplémentaires.
- Mapix fonctionne entièrement hors ligne ; aucun actif n'est téléchargé au lancement.
- Les règles de Mapix restent sous `games/mapix/` ; `app.py` ne reçoit aucune règle géographique.
- Le template ne contient aucun script en ligne.
- Aucune partie, statistique ou progression Mapix n'est persistée dans cette version.
- L'interface reste épurée et utilise la disposition Carte dominante validée.
- Toute mutation de partie passe par les méthodes verrouillées de `MapixState`.
- Les données Natural Earth sont embarquées sous leurs conditions de domaine public : <https://www.naturalearthdata.com/about/terms-of-use/>.
- La vérification finale est `python -m pytest -rs` avec zéro test ignoré.

- [ ] **Step 4: Implement strict loading and normalization**

```python
@dataclass(frozen=True, slots=True)
class Country:
    id: str
    name: str
    continent: str
    flag: str
    aliases: tuple[str, ...]


def normalize_name(value: str) -> str:
    ascii_value = unidecode(value).lower().replace("’", "'")
    return " ".join(re.sub(r"[^a-z]+", " ", ascii_value).split())


class CountryCatalog:
    VALID_CONTINENTS = (
        "africa", "europe", "asia", "north-america", "south-america", "oceania"
    )

    @classmethod
    def from_json(cls, path: Path) -> "CountryCatalog":
        rows = json.loads(path.read_text(encoding="utf-8"))
        countries = []
        for row in rows:
            if set(row) != {"id", "name", "continent", "flag", "aliases"}:
                raise CatalogError("invalid country fields")
            country_id = require_text(row, "id").upper()
            name = require_text(row, "name")
            continent = require_text(row, "continent")
            flag = require_text(row, "flag")
            aliases = row["aliases"]
            if not isinstance(aliases, list) or not all(isinstance(item, str) and item.strip() for item in aliases):
                raise CatalogError(f"invalid aliases: {country_id}")
            if continent not in cls.VALID_CONTINENTS:
                raise CatalogError(f"invalid continent: {country_id}")
            countries.append(Country(country_id, name, continent, flag, tuple(aliases)))
        countries = tuple(countries)
        return cls(countries)

    def for_region(self, region: str) -> tuple[Country, ...]:
        if region == "world":
            return self.countries
        if region not in self.VALID_CONTINENTS:
            raise CatalogError(f"unknown region: {region}")
        return tuple(country for country in self.countries if country.continent == region)
```

Implement `require_text(row, key)` as a strict non-empty-string validator. In `CountryCatalog.__init__`, reject IDs outside the 195-code union, duplicate IDs and any canonical name or alias that collides after `normalize_name`. Do not silently discard invalid rows.

- [ ] **Step 3: Implement the build-only GeoJSON-to-SVG converter**

`tools/build_mapix_map.py` must:

1. accept `source.geojson`, `countries.json` and `world.svg` paths as arguments;
2. read ISO-2 from `ISO3166-1-Alpha-2`;
3. keep only IDs in the Mapix catalogue;
4. project `(longitude, latitude)` to `((lon + 180) * 10, (90 - lat) * 10)`;
5. convert Polygon and MultiPolygon coordinates into SVG `path` data;
6. round projected coordinates to one decimal;
7. simplify each ring with Ramer–Douglas–Peucker tolerance `0.35` projected pixels while retaining at least three distinct points;
8. merge all parts of one country in one `<path data-country="XX">`;
9. add a transparent `<circle data-target-country="XX">` centered on the largest polygon when its projected bounding box is narrower or shorter than 14 pixels;
10. fail if a catalogue ID has neither path nor target.

The generated SVG begins exactly as follows:

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 3600 1800" role="img" aria-label="Carte des pays du monde">
  <g id="mapix-countries">
    <!-- paths sorted by ISO-2 code -->
  </g>
  <g id="mapix-targets">
    <!-- generated small-country hit targets -->
  </g>
</svg>
```

- [ ] **Step 3: Implement lock-scoped state transitions**

```python
class MapixState:
    def __init__(self, catalog, *, clock=time.monotonic, rng=None):
        self._catalog = catalog
        self._clock = clock
        self._rng = rng or random.SystemRandom()
        self._game = None
        self._token = None
        self._lock = threading.Lock()

    def start(self, mode: str, region: str) -> dict:
        with self._lock:
            self._token = secrets.token_urlsafe(18)
            self._game = new_game(self._catalog, mode, region, self._rng, self._clock())
            return self._payload()

    def answer(self, token, question_index, action, value) -> dict:
        with self._lock:
            self._require_token(token)
            if question_index != self._game.current_index:
                raise StaleQuestion
            outcome = apply_answer(self._game, self._catalog, action, value, self._clock())
            return self._payload(outcome=outcome)
```

Keep `_payload()` inside the lock. It returns mode, region, token, question index, elapsed time, errors, found IDs, remaining flag IDs, current canonical name, completion flags for the current question and final results only when finished. It must not return a current country ID in the public `current` object; tests may inspect `_game` only through a dedicated fixture helper.

```python
BLUEPRINT_NAME = "mapix"
URL_PREFIX = "/games/mapix"


def build_blueprint(state: MapixState) -> Blueprint:
    bp = Blueprint(BLUEPRINT_NAME, __name__, url_prefix=URL_PREFIX)

    @bp.get("/")
    def index():
        return render_template("mapix/index.html")

    @bp.post("/session")
    def start_session():
        payload = request.get_json(silent=True) or {}
        mode = require_string(payload, "mode")
        region = require_string(payload, "region")
        return jsonify(state.start(mode, region))

    @bp.get("/session")
    def get_session():
        return jsonify(state.snapshot())

    @bp.post("/answer")
    def answer():
        payload = request.get_json(silent=True) or {}
        return jsonify(state.answer(
            require_string(payload, "token"),
            require_integer(payload, "question_index"),
            require_string(payload, "action"),
            require_string(payload, "value"),
        ))

    @bp.post("/quit")
    def quit_session():
        payload = request.get_json(silent=True) or {}
        state.quit(require_string(payload, "token"))
        return ("", 204)

    return bp
```
